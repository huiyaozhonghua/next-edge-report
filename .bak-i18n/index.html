硬门槛与安全红线
  • 开发者必须完成 Pi KYC；所有队员都要各自注册（否则无获奖资格），每人只能用一个 Pi 账号。
  • 报名即须同意《Pi Next Hackathon 2026 Rules》22 条；须年满 18 岁；组织方及其母子公司的高管/员工/顾问/实习生/承包商/评委/推广机构及其直系亲属不得参赛。
  • 每队最多提交 3 个 App，且必须是主网 Pi App 或 SoloHost App；一个 App 只由一名队员提交。
  • 只能用 Pi 登录、只能 Pi 支付；禁止外链跳转、禁止法币/其他代币；不得把 App 做成导流外部平台的跳板。
  • 必须有英文名称/描述、合规 Logo（不得以 "Pi" 开头、不得用 Pi 官方 logo 与配色）、隐私政策、PiNet 集成、界面预览图。
  • Demo 视频 ≤ 3 分钟且必须公开（YouTube 等），须讲清 5 件事：这是什么、界面与功能、目标用户、解决什么问题、Pi 如何参与（Pi 登录/支付）。
  • 提交前可走一次「中期提交」拿早期反馈与曝光；最终截止：2027-01-05 23:59 PST = 北京时间 1/6 15:59。
  • 绝不输入助记词/私钥；API Key 只在服务端，不进对话。
