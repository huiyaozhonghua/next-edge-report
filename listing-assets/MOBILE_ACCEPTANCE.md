## ✅ 检查 4：Pi Browser App 里的登录（关键）

**操作**：
1. 打开 **Pi Browser** App
2. 地址栏输入 `pi://nextedgereportmv0511.pinet.com`
   （或从 App 目录里找 —— 但**上架前搜不到**，见检查 5）
3. App 加载后点右上角「**用 Pi 登录**」
4. 授权弹窗 → 批准

**成功后应看到**：
- [ ] 右上角显示 `@你的用户名`
- [ ] 「今日打卡」卡片下方变成「**已登录 · 进度云同步**」
- [ ] 刷新页面后进度还在（说明写进了 Pi 账号）

**失败怎么办**（按可能性排序）：
| 症状 | 原因 | 解法 |
|---|---|---|
| 弹窗出不来 | App 未在 Pi Browser 内打开 | 确认用的是 **Pi Browser App**，不是 Chrome |
| 提示未登录 Pi | Pi 账号未登录 | 先在 Pi Browser 里登录 Pi 账号 |
| 提示 KYC 未完成 | **KYC 未过** | 去 Pi KYC 应用完成认证（也是上架硬门槛） |
| 授权后仍显示未登录 | 服务端校验失败 | 检查是否需要代理访问 api.minepi.com |

> ⚠️ **KYC 没完成的话，登录和上架都会卡住。** 优先确认这个。

## 🌐 网络问题怎么办

如果 `pinet.com` 在你的手机上打不开（检查 1 失败）：

### 方案 A：用源站直连（绕过 PiNet）
```
https://next-edge-report.pages.dev
```
✅ 实测直连 200 / 1.4–2.8s，功能完全一样，只是没有 PiNet 外壳。
→ **录 Demo 可以用这个**，但 Demo 里要说明这是 Pi App。

### 方案 B：给手机开代理
你的电脑上跑着代理（`127.0.0.1:17891`）。
手机和电脑连同一个 Wi-Fi 时：
- 手机浏览器访问 `http://<电脑局域网IP>:17891` 作为 HTTP 代理
- 或用手机上的代理 App（推荐 Clash/Shadowrocket 等）

> ⚠️ 代理 App 可能需要订阅/配置。**如果只是为了录 Demo，方案 A 更快。**

### 方案 C：录完再测
Demo 视频可以用方案 A（源站）录，**只把登录那一段留到有代理时补拍**。
逐字稿里已经把登录段设计成独立片段 R7，就是为了这个。
